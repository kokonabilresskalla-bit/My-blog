# فيزيا ستوديو — منصة التجارب العلمية

منصة عربية تفاعلية لتجارب الفيزياء، مصممة للهاتف والتابلت والكمبيوتر.

## محرك 3D
- Three.js r160 / WebGL مضمّن محليًا في `vendor/three/three.min.js`.
- لا يوجد CDN أو تحميل مكتبات وقت التشغيل.
- الأجهزة المعملية تُبنى هندسيًا داخل JavaScript بأشكال ثلاثية الأبعاد خفيفة، بدل ملفات نماذج ضخمة.
- إضاءة وخامات معدنية وظلال وكاميرا منظور وبوصلة ثلاثية الأبعاد.
- كثافة البكسلات محدودة إلى 1.35 لتقليل حمل GPU على الأجهزة المتوسطة.
- ترخيص المحرك في `vendor/three/LICENSE` (MIT).

## أقسام المنصة
- المغناطيسية: السلك المستقيم وتجربة أورستد، الملف الدائري، الملف اللولبي، الفيض المغناطيسي.
- الميكانيكا: البندول البسيط، المقذوفات، المستوى المائل.
- الكهرباء: قانون أوم، توصيل المقاومات.
- البصريات: انعكاس الضوء، انكسار الضوء.
- الموجات: الموجة المستعرضة.

## التشغيل
HTML5 وCSS3 وJavaScript ES Modules وThree.js WebGL وService Worker وWeb App Manifest. كل ملفات التشغيل الأساسية داخل المستودع. شغّل عبر GitHub Pages أو خادم HTTPS/localhost. التخزين دون اتصال يعمل بعد أول تحميل ناجح.

## الدقة العلمية
المشاهد ثلاثية الأبعاد تمثيلات تعليمية، والقراءات تعتمد نماذج مثالية وافتراضات مبسطة وليست قياسات معملية معايرة.
