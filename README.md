# فيزيا ستوديو — منصة التجارب العلمية

منصة عربية تفاعلية لتجارب الفيزياء، مصممة للهاتف والتابلت والكمبيوتر.

## محرك 3D والتجارب
- Three.js r160 / WebGL مضمّن محليًا في `vendor/three/three.min.js` دون CDN.
- مشاهد ثلاثية الأبعاد للمغناطيسية والميكانيكا والكهرباء والبصريات والموجات.
- تحكم باللمس لتدوير الكاميرا، تكبير بإصبعين أو عجلة الفأرة، وزر عرض ملء الشاشة.
- استجابة عناصر التجربة للقيم: اتجاه البوصلة مع التيار والبعد، الفيض مع المساحة والمجال والزاوية، حركة المقذوف والبندول والموجة، وقيم المقاومات.
- تقليل كثافة البكسلات لتخفيف الحمل على الأجهزة المتوسطة.

## ألعاب الدوائر الكهربائية
- تركيب دائرة توالي من مصدر ومفتاح ولمبة ومقاومتين.
- تركيب دائرة توازي بفرعين للمقاومات.
- تحدي قانون أوم لاختيار المقاومة التي تحقق التيار المطلوب.
- اختيار وسحب وإفلات باللمس، مع إمكانية لمس القطعة ثم اختيار مكانها.
- عند إغلاق المفتاح يتم فحص اكتمال التوصيل والقيم؛ الدائرة الصحيحة تضيء اللمبة، والخاطئة تعرض عطلًا افتراضيًا للُّمبة.
- جميع الألعاب محاكاة تعليمية منخفضة الجهد وليست تعليمات لتجميع دائرة كهربائية حقيقية.

## أقسام المنصة
- المغناطيسية: تجربة أورستد، الملف الدائري، الملف اللولبي، الفيض المغناطيسي.
- الميكانيكا: البندول، المقذوفات، المستوى المائل.
- الكهرباء: قانون أوم وتوصيل المقاومات.
- البصريات: الانعكاس والانكسار.
- الموجات: الموجة المستعرضة.

## التشغيل والأداء
HTML5 وCSS3 وJavaScript ES Modules وThree.js WebGL وService Worker. الملفات الأساسية موجودة داخل المستودع ولا تعتمد على CDN. التخزين دون اتصال يعمل بعد أول تحميل ناجح عبر HTTPS أو localhost.

## الدقة العلمية
المشاهد تمثيلات تعليمية، والقراءات تعتمد نماذج مثالية وافتراضات مبسطة وليست قياسات معملية معايرة. ترخيص Three.js في `vendor/three/LICENSE` (MIT).
