# فيزيا ستوديو — منصة التجارب العلمية

منصة عربية تفاعلية لتجارب الفيزياء، بتصميم متجاوب للهاتف والتابلت والكمبيوتر.

## محرك الرسوم ثلاثية الأبعاد
- تستخدم المنصة **Three.js r160** كمحرك WebGL حقيقي، محفوظًا محليًا في `vendor/three/three.min.js`.
- حجم ملف المحرك: 669,884 بايت قبل ضغط النقل.
- لا يتم تحميل المحرك من CDN ولا يحتاج المستخدم إلى تنزيل مكتبات عند فتح الموقع.
- الإضاءة والمواد المعدنية والظلال والكاميرا الدوارة والبوصلة ثلاثية الأبعاد تُرسم على الجهاز.
- إعدادات الأداء تحد كثافة البكسلات إلى 1.5 لتقليل الحمل على التابلت.
- ترخيص Three.js موجود في `vendor/three/LICENSE` (MIT).

## أقسام المنصة
- **المغناطيسية:** السلك المستقيم وتجربة أورستد، الملف الدائري، الملف اللولبي، الفيض المغناطيسي.
- **الميكانيكا:** البندول البسيط، المقذوفات، المستوى المائل.
- **الكهرباء:** قانون أوم، توصيل المقاومات.
- **البصريات:** انعكاس الضوء، انكسار الضوء.
- **الموجات:** الموجة المستعرضة.

## التقنيات والتشغيل
HTML5 وCSS3 وJavaScript ES Modules وThree.js WebGL وService Worker وWeb App Manifest. كل ملفات التشغيل موجودة داخل المستودع، ولا توجد روابط CDN.
افتح الموقع عبر GitHub Pages بعد تفعيل Pages أو عبر خادم محلي على localhost. لا تستخدم `file://` لأن WebGL modules وService Worker يحتاجان سياق استضافة مناسبًا.

## الدقة العلمية
المشاهد تمثيلات تعليمية ثلاثية الأبعاد، والقراءات تعتمد نماذج مثالية وافتراضات مبسطة؛ ليست قياسات معملية معايرة.
