# مختبر المغناطيسية — فيزياء تالتة ثانوي

معمل افتراضي تفاعلي باللغة العربية، هدفه شرح التجارب العملية بصريًا بدل الاكتفاء بالشرح النظري.

## التجارب الموجودة
- **السلك المستقيم والبوصلة (تجربة أورستد):** تغيير شدة التيار، عكس اتجاهه، تغيير بعد البوصلة وزاويتها حول السلك.
- **الملف الدائري:** استكشاف اتجاه المجال عند مركز الملف وتأثير شدة التيار وعدد اللفات.
- **الملف اللولبي:** مشاهدة شكل المجال داخل الملف وخارجه وتغيير التيار وعدد اللفات.
- **الفيض المغناطيسي:** تغيير كثافة الفيض والمساحة والزاوية وملاحظة قيمة الفيض.

## التشغيل
المشروع static ولا يحتاج Backend أو تثبيت حزم. افتح `index.html` عبر خادم محلي أو انشر مجلد `magnetism-lab` على GitHub Pages. يحتاج اتصال إنترنت لتحميل Three.js والخطوط من CDN.

## ملاحظات علمية
المشاهد ثلاثية الأبعاد تمثيلات تعليمية وليست محاكاة مختبرية دقيقة لكل التفاصيل. قيم المجال في التجارب مبنية على العلاقات النظرية المثالية. في تجربة الفيض، الزاوية θ هي بين المجال المغناطيسي والعمود على السطح.

## النشر على GitHub Pages
من إعدادات المستودع اختر **Pages**، ثم **Deploy from a branch**، وحدد الفرع `main` والمجلد `/ (root)` إذا كنت تريد إبقاء المشروع داخل مجلد المستودع، أو انقل ملفات المشروع إلى الجذر لو أردت أن يكون الموقع الرئيسي هو المعمل.
