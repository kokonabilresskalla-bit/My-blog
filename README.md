# مختبر المغناطيسية — فيزياء تالتة ثانوي

معمل افتراضي تفاعلي بالعربي لتجارب السلك المستقيم والبوصلة والملف الدائري والملف اللولبي والفيض المغناطيسي.

## التقنيات المستخدمة
- **HTML5:** بنية الصفحات وإمكانية الوصول.
- **CSS3:** التصميم المتجاوب والواجهات والحركات، بخطوط نظام محلية دون Google Fonts.
- **JavaScript (ES Modules):** محرك الرسم التفاعلي، التحكم في المشهد والحسابات اللحظية.
- **JSON:** محتوى التجارب والقوانين منفصل عن منطق التطبيق في `data/experiments.json`.
- **Python 3:** مرجع مستقل للحسابات العلمية واختبار سلامة بيانات التجارب داخل `tools/`.
- **Service Worker + Web App Manifest:** تخزين ملفات التطبيق محليًا وإمكانية تثبيته كتطبيق ويب.

## التجارب
1. السلك المستقيم وتجربة أورستد.
2. المجال عند مركز الملف الدائري.
3. المجال داخل الملف اللولبي.
4. الفيض المغناطيسي وتغيير الزاوية والمساحة وكثافة الفيض.

## التشغيل
الموقع ثابت ويعمل على GitHub Pages. لا يحتاج إلى Node.js أو Python أو مكتبات CDN عند فتحه.
بعد أول زيارة ناجحة، يقوم Service Worker بتخزين ملفات التطبيق الأساسية لتشغيله دون اتصال في المتصفحات التي تدعم ذلك.

## أدوات Python (اختيارية للتطوير)
شغّل من جذر المستودع:
```bash
python tools/validate_data.py
python tools/physics.py
```

**تنبيه علمي:** المشاهد توضيحية تعليمية، والقراءات تقريبية حسب العلاقات المثالية الموضحة في كل تجربة.
